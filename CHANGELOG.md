# Changelog

All notable changes to Rusty Smart Stitch will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.8] - 2025-03-17

### Added
- GitHub Actions workflows for CI/CD
- Automated release process

### Fixed
- Update checker in about tab
- README shield buttons

## [1.0.7] - 2024-12-31

### Added
- Initial public release
- Core slicing and stitching functionality
- Profile system
- Multiple format support (PNG, JPG, JPEG, WebP, BMP, PSD)
- Waifu2x integration
- User-friendly GUI with main, advanced, and Waifu2x tabs
